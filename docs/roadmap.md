# 推进顺序 v0.1

这是依赖关系和验收标准，不是已发生的进度或训练耗时承诺。

## 当前完成范围

项目命名、临床问题收敛、架构/data/evaluation设计与文献核查。当前无实现代码、数据下载、付费GPU任务或模型训练。

## M0：信息与物理接口

检查CHB-MIT真实文件字段和事件/患者对应，确认可用导联及采样范围。TUH访问独立推进；没有访问时不假设已经得到TUSZ/报告。

验收：有可追溯的patient/event split，单位/参考/极性检查、DWT round-trip、CWT有效边界、条件来源账本。先选择少量患者和完整事件做QA，不直接处理所有公开EEG。

## M1：最小生成基线

先实现小型类别条件Transformer、明确DDPM协议、原始波形与完整DWT的接口。一张5090实际profiling后确定microbatch、patch和窗口。

验收：能稳定训练/采样，有生成/目标/参考路径的接口审计，保持µV尺度并检查边界和多样性。未通过时不增加融合/判别器。

## M2：三分支与结构条件

保留波形、CWT-Swin、医学文本三个编码接口与对比学习，加入ViLT式融合、文本结构调制和多尺度注入。逐步加，而非同时改变所有组件。

验收：合法partial/reference条件、缺失模态、独立控制指标、同信息数值条件对照；没有额外query输入。

## M3：现代主干与真实增强

在相同架构上比较CFM/JET路径，按患者预算进行downstream增强；TUH取得后以TUSZ展开主实验，锁定CHB-MIT或其他合法独立来源测试。

验收：完整真实患者结果、事件/时长预算、误报与多样性、预算匹配基线。模型自身相似度不是唯一证据。

## M4：必要时扩展

按实际瓶颈选择TUEV事件、TUEP疾病、长窗口、结构规划器或少步加速。JiT/MPDiT/ReGen等只在对应瓶颈确立后进入。自然视觉刺激、MRI/CT以及任意疾病泛化不属于首版。

## 研究产物

可复现数据流程、条件规范、固定评估协议、许可允许的实现/权重与报告。对所有结果区分“提案”“复现”“本项目实测”，投稿主张依据实验重写，不预先承诺顶会录用。
