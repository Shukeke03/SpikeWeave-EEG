# 训练时间与 CVPR 研究定位

更新：2026-10-08。按innovation-is-art的“问题—缺口—机制—证据”框架评估。下面分别记录本项目测量、预算估算与未验证研究假设，不能将工程测试当作生成效果。

## 当前训练时间

GPU为legion RTX3060 Laptop 6 GiB。当前是共享Stage A表征预训练：E8×512 SNN与医学C；尚未进行B对比对齐或M12×512扩散生成训练。

日间20×13配方完整optimizer update耗时：step134=89.56秒、135=89.74秒、136=88.91秒、137=88.64秒。step138期间曾短暂有另一个显存探测，127.75秒不用于独立吞吐估计。夜间8×32配方参考旧独立完整更新，step130–134约107.54–109.59秒；新的expandable allocator独立短探测通过显存验收，但尚无新夜间完整周期长期均值。

估算以日间89秒/更新、夜间108秒/更新为中心：

`50400 / 89 + 36000 / 108 ≈ 900 optimizer updates/day`。

| 预算 | 昼夜规则下预计墙钟时间 |
|---|---|
| 额外1000 optimizer updates | 约1.1天 |
| 额外10000 optimizer updates | 约11–12天 |
| 从完整父断点138到总100000 | 中心约111天，规划约110–120天 |

每天09:00–23:00约80%显存、23:00–09:00约50%。范围考虑切换、安全保存和吞吐浮动，前提是服务器持续运行；长暂停另计。100000是配置的学习率与更新预算，不是已证明达到收敛必须的次数。正式阶段时长与早停须依据验证，不以训练loss或预算耗尽替代效果。

B与C的每步时间、所需更新及总项目时间尚未实测，不能将上述111天称为完整生成模型训练时间。A/B共享E/C，因此由L元数据改为M不会使当前A获得24×1024→12×512的生成器计算量降幅。后续租用GPU前应先核验小规模开发结果，再用真实相同配方测吞吐。

## CVPR 能否作为目标

可以。CVPR2027官方范围包含多模态学习、生成与基础模型、数据合成、少样本学习、医学视觉及AI for Science，但要求高质量原创研究。EEG时频图本身不足以证明视觉方法贡献；这里的适配判断是我们对论文问题与方法的研究判断。[CVPR2027官方征稿](https://cvpr.thecvf.com/Conferences/2027/CallForPapers)。

最接近先前工作已经覆盖许多组合成分：

- JET：类别条件Transformer/flow与结构、统计约束。不能把将JET损失搬入扩散作为单独核心贡献。[JET原文](https://arxiv.org/html/2605.21280v1)。
- WaveletDiff：直接小波系数扩散、逐层Transformer、门控跨尺度交互、Parseval能量约束，且包含EEG；最新v3在2026-09-04更新。“小波+多尺度扩散”已不是独立缺口。[WaveletDiff原文](https://arxiv.org/abs/2510.11839)。
- ELM：临床EEG与真实报告对齐，用于标签高效表型分析。语言对齐也需与已有方法区分。[ICML2025 ELM](https://proceedings.mlr.press/v267/gijsen25a.html)。

SNN、ViLT、对比学习、标准小波变换与普通子空间投影是方法组成，不能因组合便声称首创。Sketch2CT与MSADN继续作为已明确归属的灵感，JET与WaveletDiff是直接方法比较对象。

建议当前论文集中检验这一主张：

> 在未见患者上，同时受病理语义和独立局部时频条件控制时，导联测量结构与完整小波结构的一致建模，可以提高联合条件满足率，同时保留对真实少样本检测有用的样本变化。

机制假设是语义与局部结构引导存在干扰，结构表示及约束能缓解失真或变化减少；该干扰和缓解都尚未在本项目观察验证。若成立，才进一步解释对比预训练和SNN分别贡献什么；若不成立，须修订主张。

当前证据缺口：仅有CHB-MIT开发库；CWT是EEG派生视图，不能称为独立临床影像；两类事件模板不是丰富真实诊断文本；默认montage_mode为audit，全库硬约束尚未批准；生成及强基线结果未测。当前数据不能支持“所有EEG、任意疾病文本可泛化”。

按已约定G0–G3推进：先完成必要审计和一个G1开发比较。对照为相同条件、相同预算的“小波扩散+简单FiLM+同样JET约束”，同时保留JET原始基线。先检查联合条件控制、基本结构质量和真实开发患者少样本增强；没有超过强基线前，不铺开完整评估矩阵。若简单融合效果相当，或收益仅来自更多条件信息，核心机制主张便缺乏支持。
