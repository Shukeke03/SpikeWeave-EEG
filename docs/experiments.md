# SpikeWeave-EEG 分阶段评估协议 v0.2

权威项目总方案见 [project-plan.md](project-plan.md)。本文件定义按开发效果推进的评估门槛；架构遵循 [architecture.md](architecture.md)，对比目标遵循 [contrastive-protocol.md](contrastive-protocol.md)，数据边界遵循 [data-protocol.md](data-protocol.md)。

状态：评估设计已确定，正式模型的真实临床效果未测。固定两条顶层表征分支 E（EEG SNN）与 C（共享医学图文条件），旧三分支仅作历史原型/架构对照。真实患者上的下游窗口 AUPRC 是主终点；连续事件检测在完整评估阶段开展。

## 推进规则

| 阶段 | 进入条件与目的 | 当前阶段运行的范围 | 下一步门槛 |
|---|---|---|---|
| G0 数据与信息流验收 | 数据、数值变换和条件来源可审计 | 必要数值/QC/泄漏审计、评估器与基线接口检查 | 必要审计通过，输入预算与合法监督明确 |
| G1 小规模开发筛选 | 模型尚未稳定达到强基线 | 小规模验证、JET/普通条件 VP、真实/重复/常规增强、小下游、少量控制/多样性/近邻 | 主开发指标达到最强已复现基线，且最低质量检查通过 |
| G2 公平强基线确认 | 候选已通过 G1 | 固定主指标与主要公平对照，3 seed、训练患者独立的开发验证 | 主指标均值领先最强基线，且至少2/3配对种子方向一致，无明显控制/结构/记忆退化 |
| G3 完整科研评估 | 开发集呈现候选 SOTA | 锁定真实测试、完整机制消融、统计/效率、合法外部队列和连续事件检测 | 完整证据支持后，才声明指定任务/协议下的 SOTA |

门槛依赖预先记录的开发指标、稳定性与成本，不规定每次改模型都运行全部实验。未达强基线时返回实现诊断和 G1。开发筛选结果仅用于筛选，不替代正式论文结果。测试集保持锁定，不能通过反复查看测试结果选择模型、属性、阈值、采样器或超参数。

G1/G2 的默认主闸门是 strict source-only、自然分布开发 query 的患者等权 AUPRC：先按患者计算 AP，再对预先规定的可计算患者取平均。pooled AP 与 K=1 support 为辅助，不能事后选最高者晋级。无正类患者的 AP 不定义，单列覆盖和背景误报，不能伪填为0或临时删除难患者。若主设置客观不可成立，在首轮运行前预注册唯一替代设置。G3沿用冻结的主设置与汇总口径。

## 所有阶段共用的信息与预算边界

- 患者/记录/事件分组先于切窗和统计拟合；CHB chb01/chb21 合并为同一规范患者。源域尺度、特征评估器及任何可学习处理只能由允许的训练数据拟合。
- Strict source-only、few-shot support、partial-observation 分开记账。表示预训练、生成器预训练、目标适配、检测器训练分别记录数据量；无标签目标 EEG 预训练属于 transductive setting。锁定 query 不参与训练、归一化或支持集构造。
- 完整目标 CWT/干净目标表征是 teacher/target。生成参考来自独立的允许源域/支持集；部分目标结构仅用于明确的 observation-conditioned 重建/inpainting 协议，不能混入盲生成或增强主结果。
- 官方事件标签模板是窗口事件监督。患者诊断、记录报告与窗口事件分别保留 scope；没有真实报告时不评估报告 bag 结果，没有诊断队列时不声明疾病诊断控制。
- 目标真实标签生成的文本或按真实标签挑选的参考，仅可用于明确提供类别的条件生成。盲测检测器不能接收由 query 真值构造的文本、参考、属性或结构。滤波、重采样与 CWT 上下文也计入支持预算，并与 query 隔离。
- 基线获得相同真实数据、标签/文本/属性、支持预算和合法参考。条件信息、医学预训练、结构与容量收益分别比较。固定逆频率采样只使用 train/source 计数，不称为动态 adaptive sampler。
- 下游比较固定模型、初始化、真实训练子集、优化器更新数、调参次数与合成数量。重复采样对照享有同等训练机会；记录真实样本曝光次数，防止将更多更新或更多正类重复当作生成收益。
- 记录全部 E/C 预训练、生成器与下游的计算成本和外部权重使用。采样比较记录实际 NFE、CFG 额外调用、wall time、显存与硬件；Heun 区间数和累积 batch 分别不等于 NFE 与对比候选池大小。

## G0：必要数据、数值与泄漏审计

G0 只验收开展效果评估必需的前提，不证明医学有效性。

1. 核对源文件/患者/事件身份、split、重复、QC、标注时间和各类合法窗数；保留未标注/未知类别及淘汰原因。非发作窗口不能解释为健康或非癫痫患者。
2. 验证 µV 单位、导联端点/极性、有效 mask、source-only RMS、反归一化、完整 signed DWT/IDWT 与 CWT 的频率/时间坐标、边界 mask。真实 montage residual 审计通过后才启用硬子空间；Q 坐标是测量模式。
3. 审计 teacher、参考、部分观察与外部条件的实际代码路径及 provenance；禁止完整目标 CWT 接入外部条件。按标签构建的 ref_index 必须与盲测输入隔离。
4. 验证条件 mask、缺失模态、全空条件与 CFG 路径。属性/局部 CWT 控制只在真实有效条件和监督存在时启用；缺失字段不是已验证的控制能力。
5. 固定自然分布开发子集、主 AUPRC 计算、事件/患者分组和评估器版本。独立事件探针/距离特征编码器仅使用允许训练数据，与生成器 E/C 分离；不能用训练头自身相似度独证生成效果。
6. 核对 JET 原论文及作者代码版本、参数化、原 loss/权重、类别采样、预处理、训练与 NFE。原始复现与预算匹配版本分别命名，记录论文/代码差异。改成 VP 或替换约束后另列改造模型。

任何必要审计失败，先修复对应问题，再开展 G1。数学/工程测试通过仅代表该检查的实现行为。

## G1：尚未达到强基线时的小规模开发筛选

### 固定小规模审查与生成预算

- 从训练患者独立的 validation 建立分层审查库：每类取 `min(256, N_val_eligible)` 个合法窗口。固定患者/事件/记录选择和随机种子，避免由一个长事件主导；保存实际患者、事件、窗口数。
- 每个生成模型、每个提供的类别条件先生成 32 个窗口，使用配对噪声种子及相同合法条件。该类别分层审查库用于生成质量诊断。
- 若使用 TS-FID/MMD，比较样本量固定为 `M=min(32, N_val_eligible)`：从审查库固定抽 M 个真实窗口，并取 M 个生成窗口；另做等样本量 real–real 参考。记录特征空间、计算定义和实际样本量。小样本距离仅作工程趋势，不给显著性或医学真实性结论。
- 小下游的开发 AUPRC 在按患者/记录/时间预先选定、保持自然发生率的真实子集计算。不能把每类等量审查库的 AUPRC 作为自然分布主结果。保留子集真实持续时间和事件数。
- 小下游使用同一冻结的源训练/支持子集与短训练预算。起始 `real:synthetic=1:0.5`，所有生成方法使用相同数量；具体窗口数由冻结的真实子集确定并记录。32 个生成审查样本不是整套增强实验的样本预算。
- 首轮使用一组配对训练 seed 筛选；有可疑退化或候选改善时小规模复跑。各方案和失败运行均记录，G1 不计算正式多 seed 显著性。

### 只运行必要对照

| 对照 | 回答的问题 |
|---|---|
| real-only | 冻结真实训练预算的下游起点 |
| real + 重复/类别平衡采样 | 收益是否来自正类曝光及训练机会 |
| real + 常规 EEG 增强 | 简单可复现增强是否已足够 |
| 原始 JET；必要时另列信息/预算匹配 JET | 相对现代 EEG 生成强基线的开发表现 |
| 普通 conditional VP/DiT | 相同信息预算下普通条件扩散的表现 |
| SpikeWeave-EEG 当前候选 | 是否值得继续投入确认实验 |

普通 VP 保留同样合法条件，采用简单 FiLM/条件 token 接口。容量、真实数据、预训练权重、训练与采样预算明确记录。基线原设置复现与统一预算实验分开，不悄然修改基线。

### 少量控制、多样性与近邻筛查

- 在 source/train 中有有效监督且模型确实启用相应属性时，先检查 `rms_uV` 与 `spectral_centroid_hz`。按允许的 source/train 分布确定 P10/P50/P90，每档使用 8 个配对噪声 seed，逐属性改变条件；其他条件固定且联合属性保持可行。记录期望/实测属性误差及方向一致性。
- 当前数据路径若没有有效属性监督，报告“未启用/待验证”，先做类别条件与合法参考筛查，不补造属性控制结果。P10/P50/P90 不能从锁定 query 拟合。
- 少量文本改写/否定、文本-only/图像-only 与合法参考变化，检查条件是否被使用；不将全部模态测试默认展开成完整消融矩阵。
- 检查同条件多 seed 的波形/事件变化、最近源训练窗口和最近事件；联合原波形、时间对齐距离与独立特征近邻查看复制。幅度/频谱或多样性明显退化、近似复制、AUPRC 持续低于强基线时，返回诊断。

G1 主开发指标须达到最强已复现基线，且最低质量检查通过；判据不能在看到结果后调整。短训练和小样本失败只提供诊断趋势，不能直接推翻正式配置。G1 只说明候选值得确认，不能称优于现有最佳。

## G2：达到强基线后的有限确认

进入 G2 前冻结候选、主 AUPRC、数据与条件协议、下游结构、增强比例、训练/采样预算和主要比较对象。使用 3 个配对 seed 复核小集合：real-only、重复/常规增强、JET、普通 conditional VP 与当前候选。只确认主要公平对照，不运行全部机制/容量/外部实验。

验证患者独立于训练患者。若患者已参与 G1 调参，结果仍称开发确认；未参加开发的锁定 test 留待 G3。报告每患者与总体 AUPRC、3 seed 波动、正类/负类样本和事件数、实际预算及失败运行。小患者数和少量 seed 的不确定性明确保留。

Few-shot 候选固定 K 个独立支持事件/记录、非发作背景时长及上下文，并记录标签秒数、窗口数和目标适配成本。K 的可行值和患者纳入规则预先确定，不能只保留增强有效的患者。Source-only 与 few-shot 分开复核。

候选主指标的3 seed均值领先最强基线、至少2/3配对seed差值为正，且无明显控制/结构/记忆退化，才进入 G3。这是开发闸门，不等于患者级统计显著性。若改进不稳定，保留结果并继续 G1 诊断，避免用全量消融消耗资源。

## G3：候选 SOTA 的完整评估

开发候选表现良好只触发完整验证。固定最终方案后，运行锁定真实测试、强基线、贡献消融、统计和效率；只有完整证据支持，才能使用“指定队列、任务、条件与预算下 SOTA”的表述。全部结果包括失败、无改善和负结果一起报告。

### 完整真实效用与生理评价

- 主终点：自然分布真实 query 上的窗口 AUPRC；辅助报告 macro-F1、AUROC、患者级结果。阈值和 checkpoint 只由开发数据选择。
- 连续事件检测：保留非发作连续背景，固定事件匹配、报警合并/冷却和阈值规则；报告事件灵敏度、误报/小时及有效测试时长。平衡片段分类不能替代连续检测。
- 生理/测量：µV 幅度、PSD、差分/瞬变、signed DWT、端点与全部时间轴、跨导联相关/相位/coherence、closure residual。硬约束天然满足 closure，需用其他指标及真实效用评估其收益。
- 条件：独立事件探针、期望属性误差、局部时间/频率/导联范围、文本-only/图像-only/联合、改写/否定、未见合法属性组合；部分观察的重建指标单列。
- 表征：患者独立检索、固定对比目标的语义/结构收益及未知关系审计。真实报告实际获得且 scope 匹配后，才启用报告 bag/MIL 评价。
- 多样性/记忆：同条件分布、条件使用与变化幅度、源训练窗口/事件近邻、重复率和成员风险检查。TSTR 可作辅助；真实 + 合成训练在锁定真实 query 上的收益是主要实用证据。

### 完整主要基线与贡献矩阵

在 G2 的主要对照之外加入 WaveletDiff，以及数据/许可/条件适配可行的相关强方法。共同可接受的类别条件任务与额外结构控制任务分别报告；原方法不支持额外条件时，不把信息不对等的结果当纯架构比较。

| 要验证的贡献 | 完整比较 | 削弱或推翻主张的结果 |
|---|---|---|
| SNN EEG 表征 | 匹配 CNN/连续时空 Transformer、保留 leaky state 移除发放、spike-only/混合读出；必要时 patch4/8/16 与 PLIF/SE-adLIF | 收益来自容量/连续旁路，或瞬变/下游无改善 |
| 两分支对齐 | 无对比、逐项移除固定 semantic/structure loss、完整目标；模态打乱作负控制 | 仅训练头相似度提高，独立控制/效用无收益或多样性下降 |
| 共享图文交互 | 同信息 FiLM/晚融合、直接 patch 共享交互、BiomedCLIP 前端 + 共享融合；单模态另列信息消融 | 简单融合同样有效，或收益仅来自医学预训练 |
| 小波域与多尺度 | raw VP 与完整 signed DWT VP，匹配条件、clean 参数化、容量和实际 NFE | 收益仅来自 token/参数预算差异，或端点瞬变受损 |
| 六类软约束 | 全关、逐组移除、完整约束；JET 原 TV 与差分匹配另比较 | 约束无效、损害变化，或控制项无合法监督 |
| 全过程测量约束 | 无约束、软 closure、仅最终 QQ^T 投影、全过程子空间 | 最终投影同样有效，或真实残差不支持严格子空间 |
| 类别采样与容量 | 自然分布/统一固定逆频率；JET 原采样另列；DiT 中/大/XL | 改善由类别曝光或容量解释，无法归因新机制 |

逐项消融保持其他条件和训练预算。对预期交互显著的模块，可预先指定小规模二因素比较；不默认穷举全部组合。容量/NFE/CFG 扫描先在开发集完成，测试阶段只评估冻结的设置。

### 统计、外部与效率

- 至少 3 个配对 seed；按患者聚类的置信区间/配对差异，必要时嵌套事件层级。相关窗口不能当独立统计样本；报告小患者数造成的不确定性。
- 预注册主比较、主终点及多重比较处理；保存所有运行、调参次数、中止原因和计算成本，避免只展示最佳 seed 或有利指标。
- 获得合法独立队列后开展跨来源测试，核对子库/患者/记录重复、montage、采样、人群与标签范围。来源参与开发后不再称完全未见来源；CHB→TUH 的差异不能仅解释为医院差异。
- 报告相同信息/真实数据预算下的效用和相同训练/采样成本下的效用；固定合成量、各阶段 FLOPs/时间、参数/显存、真实 NFE、CFG 与下游成本。前端医学预训练权重及其额外优势单列。

JET、WaveletDiff、ELM/CLEF 和 SpikeWavformer 等贡献准确归属；Sketch2CT 与 MSADN 保留为已说明的灵感。模块组合、工程验收或单次开发胜出不自动构成创新证据或 SOTA 结论。
