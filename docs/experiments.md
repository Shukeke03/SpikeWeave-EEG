# 实验、证据与反证 v0.1

当前没有实验结果。以下是要检验的主张、控制条件及失败标准。

## 1. 主张与证据

| 拟检验主张 | 必需证据 | 削弱/否定条件 |
|---|---|---|
| 联合语义/结构比粗类别条件更可控 | 同信息/预算比较事件、时频、空间控制误差 | 数值属性 FiLM 达到相同效果 |
| 三分支对齐提高条件表示 | 开关对齐、模态打乱、改写文本、缺失模态 | 只提高训练编码器相似度，独立 probe/生成无改善 |
| 小波建模有额外价值 | raw/DWT 生成空间、CWT条件开关、细节loss开关 | 收益来自更大容量、信息或预算；DWT无优势 |
| 保留有用变化 | 同条件多种子分布、最近邻和患者样本覆盖 | 合成样本复制、塌缩或只输出平均波形 |
| 改善少样本真实检测 | 患者独立真实连续测试、相同真实样本和detector | 控制更好但真实检测没有稳定收益 |
| 可跨来源迁移 | 独立队列、无重叠患者及规范support预算 | 仅混合随机窗口有效，锁定患者/来源失效 |

## 2. 强基线

1. 真实数据训练的 detector，不加合成；与常规信号增强对照。
2. 相同骨干的类别条件 DDPM/DiT。
3. 相同数值结构信息的 FiLM/adaLN 条件版，去掉复杂 fusion。
4. JET 类别条件原波形 CFM，优先复现可取得作者配置；再做预算匹配版本。
5. 真实参考片段受约束增强/模板＋多通道残差等较简单方案。
6. GenEEG 机制相关对照；代码授权不明/受限时不直接复制，其可比较范围和独立实现差异记录清楚。

三分支主方案不能比基线额外获得完整目标 CWT、额外患者数据或更多支持记录。需要分开信息收益与架构收益。

## 3. 最小消融矩阵

先做少量有判别力的实验，不全排列所有组件。

| 编号 | 比较 | 固定内容 |
|---|---|---|
| A | 类别条件 vs相同属性数值条件 vs三分支融合 | 源数据、目标条件、骨干、更新数 |
| B | 三分支对比学习开/关 | 条件编码器和额外训练预算匹配 |
| C | 完整DWT空间 vs原波形空间 | 采样信息、DDPM目标、同尺度/参数预算 |
| D | CWT结构条件开/关、错误匹配结构 | 三分支架构其余部分 |
| E | 文本、参考各自删除/打乱；文本改写 | 其他有效条件一致 |
| F | 同主干DDPM vsCFM；velocity vsclean prediction后续 | 空间、conditions、NFE/预算定义 |
| G | 多尺度注入 vs一次concat/cross-attention | 同条件信息与参数预算 |

小波损失、FiLM、融合深度后续只针对观察到的瓶颈增加消融。所有对照报告参数、训练样本、updates、实测显存/耗时和采样 NFE。

## 4. 条件控制

根据真实标注可支持的字段检验：事件类型、窗口内起止/覆盖、允许频带能量范围、活动导联/区域。评价输入条件来自用户设定或允许support；查询目标的真值只用于独立评估。

采用冻结的独立 EEG probe 或明确计算的物理属性，不只用模型自己的训练对比编码器。没有额外专家资源时，表述为专家标注事件和信号属性的一致性，不冒充临床可使用验证。

改变单一条件时保持其他输入和随机种子，检查目标属性变化及非目标属性漂移。属性之间可能耦合；不能用数值变化直接证明独立可解耦的生理因素。

若任务要检验同一文字改写稳定性，保留同一语义/属性，而不是给改写额外增加精确结构数字。

## 5. 结构与真实性

- 分频率 PSD、频带功率与局部时频包络；保留低能量与高频事件的评价。
- 振幅、斜率、峰宽、事件形态与窗口内非平稳变化。
- 在相同参考/montage下的跨导联协方差、cross-spectrum及已知lead consistency。
- DWT/IDWT数值和边界伪影；不要把任意相邻平滑当生理合理。
- TS-FID等分布指标仅作辅助，固定特征提取器、样本数和估计协议。

这里的跨导联统计不是脑功能连接/疾病因果机制证据。CWT功率相似也不能单独证明相位、波形或疾病状态正确。

## 6. 多样性与复制

同条件生成多种子样本，测量波形、频谱、结构和患者风格的分布范围。与真实类内/患者内变化比较，不要求每次生成唯一对应某个真实trial。

在所有真实训练片段中做最近邻检索，至少分别检查波形对齐后的距离与结构特征距离，并查看最相似样本。防止通过重叠窗口、相同参考或目标条件把原波形复现称为增强。

生成时允许的参考样本要纳入复制评估。隐私问题不能仅凭扩散或条件缺失声称已经解决；首版只报告可测的复制风险结果。

## 7. 少样本临床效用

预算按患者/事件和实际记录时长定义，避免把同一长事件拆成许多片段当独立K-shot。source-only和target-support单独报告。

比较多个真实数据预算、至少多个随机选择种子。每个预算下 detector相同，真实训练集相同，合成量比例用验证集选。低样本 detector或阈值不允许由锁定测试患者调参。

核心指标：连续记录上的事件灵敏度、每小时误报、事件/片段级AUPRC及适合数据的置信区间。不同采样的平衡切片accuracy不足以证明真实检测改善。

不确定性以患者为重采样单位或遵循事件/患者层级，不把高度相关窗口视为独立统计样本。报告每患者变化和失败患者，避免只报一次最佳均值。

## 8. 推进与停止条件

原型先通过数据/物理重建与患者划分，再做A/B/C关键对照。出现以下结果时必须改设计或缩小主张：

- 三分支只提高matching score且多样性下降。
- 小波域收益在参数/条件信息匹配后消失。
- 复杂fusion不优于直接数值FiLM。
- 外部来源/未见患者检测无改善或误报增加。
- 支持集预算或查询信息审计失败。

出现这些情况不意味着整个项目必然失败：可以保留明确有效的条件/数据规范，但不能用更多模块掩盖核心实验的否定。
